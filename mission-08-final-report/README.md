## 3. Challenges Faced

The biggest challenge I faced was learning Git and GitHub because version control was relatively unfamiliar territory for me.

I initially found it challenging to understand how local repositories, remote repositories, branches, commits, pushes, and pull requests work together.

I also encountered repository synchronization issues and had to learn how to fetch changes, merge updates, resolve differences, and use cherry-pick to move a specific commit onto the correct branch.

Working through these issues helped me understand version control through practical experience rather than simply memorizing commands.

My Mission 6 pull request also encountered a merge conflict in the root README.md because both branches contained changes to the same file. I left the pull request open without merging it, following the assignment instructions.
