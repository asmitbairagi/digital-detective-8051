# Mission 3 — Operating Systems

## 1. Objective
To understand the role of an operating system, process management, file permissions, paths, and storage management.

## 2. Operating System
An operating system (OS) manages computer hardware and software resources and provides an environment for applications to run.

Examples include macOS, Windows, Linux, Android, and iOS.

## 3. Processes and Process Management
A program is a set of instructions, whereas a process is a program currently being executed.

Commands explored:
- `ps` — displays running processes.
- `ps aux` — displays detailed process information.
- `top` — monitors processes and system activity in real time.

Process management allows the OS to coordinate running applications and allocate CPU time.

## 4. Paths
- Absolute path: starts from the root directory (`/`).
- Relative path: specifies a location relative to the current working directory.

Example:
`../mission-03-operating-system/README.md`

## 5. File Permissions
The permission symbols are:
- `r` — Read
- `w` — Write
- `x` — Execute

Numeric permission values:
- Read = 4
- Write = 2
- Execute = 1

For example, `755` represents `rwxr-xr-x`.

## 7. OS Responsibilities
The major responsibilities of an operating system include:
1. Process management
2. Memory management
3. File management
4. Device management
5. Security and permissions
6. Providing a user interface
