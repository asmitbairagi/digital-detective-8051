# Digital Detective

## About This Project

This repository contains my work for the Digital Detective Independent Learning Assignment.

The objective is to explore computer fundamentals, understand operating systems, practise Terminal commands, learn Python programming, explore number systems, understand Git and GitHub, and study computer networking.

## Topics Covered

- Computer hardware and software
- Input, Processing, Output and Storage (IPOS)
- Terminal and command-line operations
- Operating systems, processes and permissions
- Python programming and how programs execute
- Binary, decimal, octal and hexadecimal number systems
- ASCII and UTF-8 character encoding
- Git, GitHub, branches and Pull Requests
- Computer networking, DNS, routers and protocols

## Running the Number Converter

The number converter is available in:

`mission-05-numbers-data/number_converter.py`

To run it:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

## Learning Summary

Through these missions, I developed a better understanding of how computers work, from their hardware components and operating systems to the software running on them.

I learned to navigate the Terminal, manage files and directories, understand processes and permissions, and work with absolute and relative paths.

I explored how Python programs execute, wrote and tested Python scripts, and learned how different number systems and character encodings work.

I also gained practical experience with Git and GitHub, including commits, branches, pushing changes and creating Pull Requests.

Finally, I explored networking concepts such as LAN, MAN, WAN, DNS, routers, protocols, packet switching, latency and bandwidth. I also used `ping` and `nslookup` to test network connectivity and DNS resolution.
