## 5. What Is a Repository?

A repository is a storage location for a project. It contains the project's files and can track changes made to them using Git. GitHub allows the repository to be hosted online and shared.

## 6. Why Is the Folder Structure Organised by Mission?

The folder structure keeps the work organised and makes it easier to find the files related to each mission. Each mission has its own README so that its tasks, learning, evidence and progress can be documented separately.
