# Mission 1 — Computer Fundamentals

## 1. Objective

Understand the fundamental functions of a computer, the difference between hardware and software, and how computers are used in everyday systems.

## 2. IPOS Model

IPOS stands for Input, Processing, Output and Storage. These four functions describe how a computer handles data.

- **Input:** Accepts data and instructions from users or other devices.
- **Processing:** Performs calculations and operations on the input data.
- **Output:** Presents the processed information to the user.
- **Storage:** Saves data and information for future use.

### Example: Calculator

When entering 25 + 35 into a calculator:

- Input: Entering 25 + 35.
- Processing: Performing the addition.
- Output: Displaying 60.
- Storage: Saving the calculation history, if supported.

## 3. Hardware Examples

Hardware refers to the physical components of a computer.

| Component | Type              | Purpose                                          |

| RAM       | Primary memory    | Temporarily stores data used by running programs |

| CPU       | Processing unit   | Executes instructions and performs calculations  |

| SSD       | Secondary storage | Stores files and programs permanently            |

| Keyboard  | Input device      | Allows users to enter text and commands          |

## 4. Software Examples

Software consists of programs and instructions that tell computer hardware what to do.

| Software         | Category                       | Purpose                                           |

| Windows          | Operating System               | Manages computer resources                        |

| VLC Media Player | Application Software           | Plays audio and video                             |

| Python 3         | Programming Language / Runtime | Allows Python programs to be written and executed |

| Wuthering Waves  | Application Software           | Provides an interactive gaming experience         |

## 5. Everyday Computer Systems

### Smartwatch
- Purpose: Tracks fitness, displays notifications and monitors activity.
- Input: Touchscreen, accelerometer and heart-rate sensor.
- Processing: Analyses sensor readings and calculates activity metrics.
- Output: Screen notifications, vibration and activity summaries.

### Laptop
- Purpose: Used for programming, browsing, gaming and productivity.
- Input: Keyboard, touchpad and microphone.
- Processing: CPU and GPU execute instructions and process data.
- Output: Display, speakers and connected devices.

### Smart Refrigerator
- Purpose: Stores food and manages cooling with additional smart features.
- Input: Temperature sensors, touchscreen and door sensors.
- Processing: Controls cooling based on temperature readings and settings.
- Output: Cooling adjustments, display information and alerts.

### Smart TV
- Purpose: Displays television channels, streaming content and applications.
- Input: Remote control, voice commands and network data.
- Processing: Decodes audio/video and runs applications.
- Output: Picture on screen and sound through speakers.
